# AeroSage — standalone AeroMatrix chatbot backend

This package supplies the intelligence service for **AeroSage — Your AI Environmental Copilot**. Its voice/avatar interface is a separate package. Neither package contains or retrains the pollutant models.

## Quick start (Windows)

1. Install 64-bit Python 3.12 or newer.
2. Run `SETUP_CHATBOT.bat`.
3. Edit `.env`: set `GEMINI_API_KEY`, your accessible `LLM_MODEL`, and `AEROMATRIX_ML_API_URL`.
4. Start the separately exported ML backend on port 8000.
5. Run `START_CHATBOT.bat`. The chatbot defaults to `http://127.0.0.1:8010`; OpenAPI docs are at `/docs`.
6. Run `TEST_CHATBOT.bat` for unit tests and actual service checks.

Default provider: Gemini REST; default model: `gemini-3.5-flash-lite`, a stable model listed in Google's model catalog at development time. Model access and quotas depend on the supplied key. Change the model in `.env` if necessary. Nothing automatically purchases credits or switches to another provider. Google may limit or charge API use according to the key's project settings. Free-tier availability is not guaranteed.

The system is a hybrid: SQLite FTS5 BM25 retrieves a verified project knowledge snapshot; an allowlisted read-only adapter obtains actual numerical results from the existing ML service; Gemini supplies project explanations and general answers. Numeric pollution results are formatted directly from API responses rather than generated by an LLM. Without an LLM, project retrieval and connected data queries still work, but general conversation and translation are unavailable.

Session history stays in `runtime/conversations.sqlite3`, is bounded to 12 turns, and expires after 24 hours by default. Every session has an independent secret token; keep it private. All app context is unverified selector/reference data. No audio is accepted by this backend; the optional voice UI sends transcripts through the same chat endpoint.

Read `CHATBOT_INTEGRATION_GUIDE.md`, `API_CONTRACT.json`, and `EXPORT_VERIFICATION_REPORT.md` before handoff. No provider key, virtual environment, raw training dataset, or LLM weights are included.
