# Provenance and attribution

- Starting data: `Pune_Pimpri_Chinchwad_Air_Quality.csv`, provided by the user. Schema declares `source=cpcb_caaqm`; the source label is not independent authentication of every row. Exact SHA-256, units, counts and periods are in `data/audit.json`. No other pollution dataset is merged.
- Coordinates: [MPCB reply filed with the National Green Tribunal, Annexure R1-IV, printed page 342](https://www.greentribunal.gov.in/sites/default/files/news_updates/Affidavit%20in%20Reply%20by%20R-1%20in%20OA%20No.48-2025%20%28page%20nos.245-352%29.pdf). Exact matching stations: Hadapsar, Revenue Colony-Shivajinagar, Katraj Dairy, Panchawati Pashan (underscore normalized), Dhankawadi. The source page was visually checked. No city-center coordinates are substituted for missing monitors.
- Weather: [ERA5 hourly single levels](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels), accessed using [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api) with `models=era5`, nearest grid and downscaling disabled. Direct CDS access requires account/credentials not supplied here. The public redistributor returned genuine ERA5 records. Per-request variables, dates, returned grids, units, cache hashes and retrieval time are in `data/weather_provenance.json`.
- ERA5 is model/observation reanalysis, not measured station weather. Two requested 0.25-degree grids cover five stations; these are not five independent weather measurements. No paid API is required for this local package.
- Attribution: Generated using Copernicus Climate Change Service information. ERA5 DOI [10.24381/cds.adbb2d47](https://doi.org/10.24381/cds.adbb2d47); ECMWF/C3S and Open-Meteo. Open-Meteo data attribution is CC BY 4.0. Its public endpoint's noncommercial usage limits apply. User-provided pollution provenance is retained; public redistribution rights have not been independently established.
- Timestamps lack explicit timezone and publication time in the CSV. Asia/Kolkata and hourly interval-end semantics are explicit assumptions. Do not represent historical replay as current data or operational publication-latency validation.
